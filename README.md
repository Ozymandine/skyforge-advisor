# SkyBlock Companion

Use the reference images and keep them in mind when building this site

Project Name: SkyBlock Assistant Aesthetic & Theme: Sleek, dark glassmorphism layout with background blur over a custom Minecraft environment header. Deep slate panels, high-contrast typography, emerald green (#22c55e) progress bars, and subtle borders. Top search command bar (Cmd/Ctrl+K), profile quick-switcher pill (Ozymandine - Grapes), refresh button, notifications, and settings icon in header.

Please generate the full sidebar navigation hierarchy and page routes:

1. GENERAL

/dashboard (Dashboard): Main command center overview featuring high-level account completion, active profile summary, and key highlights.

2. PROGRESSION

/skills (Skills): Grid of progress cards for every SkyBlock skill (Combat, Mining, Farming, Fishing, Foraging, Enchanting, Alchemy, Taming, Carpentry, Runecrafting, Social, Hunting) showing current level, precise XP progress counters (e.g. 1.32K / 100K XP), percentage, and emerald progress fill bars. Total SkyBlock Level & XP banner at top.

/collections (Collections): Categorized view tracking item collection tiers and unlock completion percentages.

/inventory (Inventory): Full interactive viewer for Ender Chest, Wardrobe, Armor, Backpacks, and Accessory Bag.

3. ECONOMY

/bazaar (Bazaar): Live market pricing, buy/sell order tracking, and high-margin flipping opportunities.

/auction-house (Auction House): Lowest BIN lookup, item price histories, and live auctions tracker.

/net-worth (Net Worth): Full breakdown of total portfolio valuation across purse, bank, inventory, armor, and storage.

4. TOOLS

/advisor (Advisor): "What should I do next?" recommendation matrix pointing out the lowest cost-per-stat or cost-per-level progression upgrades.

/goals (Goals): Custom goal setup, target trackers, and daily/weekly task checklists.

/analytics (Analytics): Historical skill XP gain charts, net worth trends over time, and event history.

/wiki (Wiki & Item Guide): Searchable item database, lore viewer, recipe trees, and texture rendering.

5. PROFILE

/notifications (Notifications): Alerts for market flips, outbid notifications, and goal achievements.

/settings (Settings): API key management, theme adjustments, texture pack fallback preferences, and profile sync settings.

Sidebar Footer: User profile card showing active username (Ozymandine), active profile (Grapes), and sync status indicator.

Populate all views with realistic mock data and maintain the exact clean dark-mode glass styling visible across the Skills page.
